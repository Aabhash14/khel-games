# Bagh-Chal (बाघ चाल)

**Status:** Planned

The traditional Nepali board game: 4 tigers against 20 goats on a 5x5 grid. Tigers win by capturing goats; goats win by trapping every tiger.

- **Vibe:** Nepal's own classic strategy game, carved-wood board
- **Modes:** play against the computer (easy, medium, hard) or with a friend on the same device
- **Play as:** tigers or goats
- **Extras:** move undo, rules tutorial, win/loss stats
