# Momo Rush (मःम रश)

**Status:** Planned

Run a street momo stall. Fold momos, steam them and serve them with achar before customers lose patience. Each day gets faster and busier.

- **Vibe:** Kathmandu evening, steamer baskets, street stall
- **Controls:** tap or click stations (fold, steam, plate, serve)
- **Progression:** day-by-day levels, new fillings (buff, chicken, veg) and jhol momo
- **Extras:** tips and upgrades between days, best day score
