# Tihar Diyo (तिहार दियो)

**Status:** Planned

Puzzle game. Rotate tiles so the oil path connects and every diyo on the house lights up. A new house each level.

- **Vibe:** Tihar night, rangoli, marigold garlands, glowing lights
- **Controls:** tap a tile to rotate it
- **Progression:** hand-made levels that grow from 3x3 to bigger grids
- **Extras:** move counter, star rating per level, progress saved in the browser
