# Nepali Games

A collection of small browser games with Nepali vibes. Each game is a self-contained folder of plain HTML, CSS and JavaScript (no build step, free to host).

| Folder | Game | Status |
|---|---|---|
| [changa-chet](changa-chet/) | Dashain kite fight | Playable |
| [bagh-chal](bagh-chal/) | Tigers & Goats board game | Planned |
| [momo-rush](momo-rush/) | Momo stall time-management | Planned |
| [tihar-diyo](tihar-diyo/) | Light-the-diyos tile puzzle | Planned |
| [himal-climb](himal-climb/) | Himalayan climbing arcade | Playable |
| [bato-harayo](bato-harayo/) | Lost at night: a story game of strangers and directions | Playable |
| [mol-molai](mol-molai/) | Dashain bazaar haggling: bluff, read faces, bring home the change | Playable |
| [indra-jatra](indra-jatra/) | Eight days of Yenya: raise the Yosin, dare the Lakhey, pull Kumari's chariot | Playable |

Hosted URLs will look like `yourdomain.com/nepali-games/changa-chet/`.

## Shared style
- Colors: prayer-flag blue, white, red, green, yellow, plus Nepal-flag crimson
- Dhaka-weave patterns in menus, Himalayan skylines, Devanagari accents (चेट!, जित!)
- Sound generated in code: madal-style beats and original folk-style tunes (no audio files, no copyright issues)
- Nepali / English language toggle
